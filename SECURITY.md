# Security

Please report a vulnerability in this library or in the AY Inbox API by email to team@ayinbox.com. Do not open a public issue for it.

Include what you found, how to reproduce it, and the version of the crate you used. We will reply to confirm we received it.

Never paste a real API key into an issue, a pull request or a log you share. If a key was exposed, revoke it in the dashboard and create a new one.
